# iPhone 문자 → 공유 Google Sheets

정상 승인 문자는 최초 단축어 자동화 설정 후 GAS가 직접 시트까지 기록한다. 웹을 열거나 매번 승인할 필요는 없다. 중복 의심·미해석·매칭 불가 취소만 검토한다.

1. 소유자가 [GAS/카드 설정](../docs/sms-setup.md)을 완료한다.
2. 웹 관리 → 기기 → **iPhone 간편 연결**에서 가족과 GAS 주소를 골라 설정 파일을 만든다. UUID/키를 직접 타이핑하지 않는다.
3. [동작별 레시피](sms-shortcut-template.json)의 setup/actions대로 Apple 단축어를 만든다. 설정 JSON을 텍스트 → 사전으로 읽고 endpoint/deviceId/token/senders를 사용한다.
4. 메시지 자동화는 카드사 실제 발신자로 한정하고 즉시 실행을 선택하여 본문을 단축어 입력으로 전달한다. OTP·인증번호·비밀번호는 전송하지 않는다.
5. UUID와 ISO8601 시각은 한 실행에서 한 번 생성하고 재시도에서는 유지한다. UUID는 실제 SMS 원본 ID가 아닌 실행 식별자다. 같은 문자를 새 실행으로 보내면 서버의 지문 검사로 중복 의심 검토된다.
6. 응답의 ok와 code를 함께 확인한다. CREATED는 이미 시트 기록 완료다. 토큰이나 원문을 실패 알림에 표시하지 않는다.

레시피 JSON은 Apple이 서명한 .shortcut 설치 파일이 아니다. iPhone의 잠금 상태·OS 버전에서 본문 전달과 무확인 자동화가 가능한지는 실기기로 확인해야 한다. PWA 자체가 SMS를 읽지는 못한다. 설정/단축어를 공유하지 말고 기기 분실 시 Devices.enabled=false로 차단한다.
