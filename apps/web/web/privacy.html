가족이 함께 사용하는 가계부 paylog의 안내입니다. 로그인 없이 확인할 수 있습니다.

1. 처리 목적과 데이터 저장 위치

paylog는 Google 계정으로 사용자를 구분하고, 사용자가 선택한 Google Sheets 원장에 가족의 수입·지출을 기록·조회·수정하는 서비스입니다. 선택적으로 Android 보조 앱 또는 iPhone 단축어로 카드 결제 문자를 전송할 수 있습니다.

웹 가계부 데이터는 사용자가 연결한 Google 스프레드시트에 저장됩니다. 문자 수집을 사용하는 경우 원장 소유자가 설정한 Google Apps Script(GAS)가 요청을 처리합니다. 별도의 paylog 중앙 가계부 데이터베이스는 운영하지 않습니다. 시트에 접근할 수 있는 사람은 Google 공유 권한과 앱의 멤버 설정에 따라 달라집니다.

2. 처리하는 정보

  • Google 계정: Google 사용자 식별자, 이메일, 이름 등 계정 프로필을 로그인·멤버 식별에 사용합니다. 원장의 Members에는 식별자·이메일·이름·역할·활성 상태 등이 저장됩니다.
  • 가계부: 거래 날짜·종류·금액·사용처·메모·카테고리·결제수단·가족 멤버 식별자·수정/삭제 상태와 처리 시각, 카드사·마스킹된 카드 식별정보 등을 사용합니다. 카드 비밀번호나 전체 카드번호를 입력하지 마세요.
  • 문자 수집 선택 시: 허용 발신자의 번호, 새 문자 본문, 수신 시각, 메시지 ID(제공될 때), 기기 ID와 인증 토큰을 전송·처리합니다. 본문에서 추출한 거래 후보, 본문 해시·중복 방지 정보·처리 결과를 원장에 기록합니다.
  • 접속 정보: Firebase Hosting·Google API·GitHub 등 서비스 제공자는 요청 처리와 보안 목적으로 IP 주소·브라우저 정보·접속 로그를 처리할 수 있습니다. 웹 홈페이지에는 사이트 소유권 확인을 위한 Google 태그(gtag.js)와 Google 태그 관리자(GTM-KQQ9XCLC) 스니펫이 포함됩니다. 해당 태그의 분석 데이터 수집은 ga-disable 설정으로 비활성화하며, 가계부 거래·문자·계정 정보나 사용자 행동을 분석 이벤트로 보내지 않습니다. 태그 스크립트 또는 JavaScript 비활성 시 대체 iframe을 불러오는 과정에서 Google은 IP 주소·브라우저 정보 등 요청 정보를 처리할 수 있습니다. 태그 관리자에 새 태그를 추가·게시하면 데이터 처리 방식이 바뀔 수 있으므로 그에 맞춰 이 방침을 갱신합니다. 광고 추적 목적으로 사용하지 않습니다.

3. Google 권한과 이용 제한

로그인은 openid·email·profile 범위를 사용합니다. 사용자가 별도로 동의하면 Google Sheets 읽기·쓰기 권한을 요청합니다. 이 권한 범위는 특정 시트 한 개로 제한되지 않지만, 앱 기능은 사용자가 입력·연결하거나 앱에서 생성한 시트를 대상으로 작동합니다. 실제 접근 가능 여부는 Google 계정의 시트 공유 권한에 따릅니다.

Google API에서 얻은 정보는 사용자에게 제공하는 가계부 기능과 그 보안·유지에 사용합니다. 판매, 광고 타기팅, 일반화된 AI/머신러닝 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용과 다른 앱으로의 전달은 Google API Services User Data Policy의 Limited Use 요구사항을 준수합니다.

Google 액세스 토큰은 웹앱 실행 중 메모리에 보관하며 앱 코드에서 브라우저 영구 저장소에 저장하지 않습니다. Google 로그인 페이지의 쿠키 등은 Google 정책이 적용됩니다.

4. 문자 수집과 기기 저장

Android 보조 앱은 사용자가 SMS 수신 권한을 허용하고 수집을 켠 이후 도착한 허용 발신자의 새 문자를 처리합니다. 과거 SMS함을 읽거나 다른 앱 알림을 수집하지 않습니다. 기기 설정·토큰·미전송 문자는 Android Keystore를 이용해 암호화하여 앱의 백업 제외 저장소에 보관합니다. 대기열은 최대 100건이며 7일이 지난 항목은 다음 작업 실행 때 정리됩니다. 장기간 오프라인이면 정리도 늦어질 수 있습니다.

GAS는 처리 중 본문과 원본 기기 토큰을 받지만, 서비스 코드에서 이를 서버 저장소나 로그에 남기지 않습니다. 서버에는 토큰 해시, 본문 해시, 처리 결과와 필요한 최소 거래 후보를 저장합니다. 웹의 수동 메모나 사용자가 별도로 만든 로그·백업에 직접 입력한 내용은 이에 포함되지 않습니다.

iPhone 단축어에는 사용자가 입력한 기기 토큰과 문자 입력이 포함될 수 있습니다. 단축어 공유·내보내기 전에 토큰을 제거하고 iCloud 동기화·클립보드·실행 기록도 확인해 주세요.

5. 공유와 외부 서비스

가족 원장은 소유자가 공유한 계정에서 접근할 수 있습니다. GAS는 원장 소유자의 권한으로 실행되므로 기기 권한은 별도의 기기 등록·토큰 검증으로 제한합니다. paylog가 광고업체에 계정·거래·문자 정보를 제공하거나 판매하지는 않습니다.

Google 로그인·Sheets·Apps Script·Firebase Hosting에는 Google 개인정보처리방침이 적용됩니다. Android APK 다운로드와 공개 문의에는 GitHub 개인정보처리방침이 적용됩니다. 외부 서비스의 처리 위치·보관과 국제 전송은 각 제공자의 정책과 계정 설정에 따릅니다.

6. 보관·정정·삭제·권한 철회

  • 원장 데이터는 사용자가 시트의 행이나 파일을 삭제할 때까지 남을 수 있습니다. 앱에서 거래를 삭제하는 것은 삭제 상태를 표시하는 방식이며 원본 행의 즉시 완전 삭제가 아닙니다. 완전 삭제를 원하면 원장 소유자가 해당 원본 행·검토/처리 기록과 별도 사본을 확인해 삭제해야 합니다.
  • Google Drive 휴지통·버전 기록·백업의 보관은 Google 정책에 따릅니다. 내려받은 CSV·APK 또는 사용자가 만든 복사본은 별도로 관리해야 합니다.
  • 로그아웃·연결 해제는 앱 세션을 정리하지만 원장 자료를 삭제하지 않습니다. Google 계정 연결 관리에서 앱의 Google 접근을 철회할 수 있습니다. 가족의 시트 접근은 Google 공유 설정에서도 제거해야 합니다.
  • 문자 수집 중지·분실 기기 차단은 기기 비활성화와 토큰 교체로 처리합니다. 진행 중인 요청은 이미 처리됐을 수 있습니다. 기기의 대기열 삭제·앱 삭제, 필요 시 GAS 배포 중지도 수행해 주세요.
  • 정보 열람·정정·삭제 및 처리 중지 요청은 아래 문의처 또는 원장 소유자에게 할 수 있습니다. 다른 가족의 정보 보호를 위해 요청자 확인과 권한 확인이 필요할 수 있습니다.
